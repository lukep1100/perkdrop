# PerkDrop mobile

Expo React Native consumer app for iOS and Android. The production catalogue remains the single source for public listings. This is an initial discovery slice, not an App Store release build.

From `mobile/`, run `npm install`, `npx expo install --fix`, then `npm start`. Run `npx expo-doctor` before EAS builds. Verify on physical iOS and Android devices before distribution.

Next: bring venue grouping and geolocation parity with the website, map, saved offers and consumer account flows, notification consent and delivery, image asset and accessibility checks, deep links, privacy disclosures, device QA, store screenshots, and signing. Do not submit until those flows are verified.
